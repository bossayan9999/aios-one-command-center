# Output Validation
## Purpose
Validate task output against requirements, evidence, policy, and confidence.
## When to use
Use before completion, publication, or learning.
## Required inputs
Task request, output, evidence, and acceptance criteria.
## Permitted tools
Output/evidence reads and deterministic validators.
## Prohibited actions
No evidence fabrication, self-approval, or hidden requirement changes.
## Execution steps
Map claims to evidence, check criteria, identify gaps, and assign status.
## Evidence requirements
Each pass/fail must cite the relevant output or evidence.
## Output format
Validation matrix, confidence, defects, and disposition.
## Validation and rollback
Reject or return output for repair when checks fail.
