# Phase 1J — Workspace Organizer and OSINT Research Desktop

## Scope

- Workspace Organizer Specialist
- safe workspace file model
- inbox, projects, OSINT, evidence, reports, knowledge, generated, and archive folders
- automatic classification and filing
- duplicate detection
- archive and undo
- File Explorer interface
- OSINT framework tabs
- Obsidian Brain Vault project and case indexes
- mobile-friendly navigation
- security tests

## Safety boundaries

- organizer never manages Git-controlled application source folders
- path traversal is blocked
- deletions are not automatic
- archive is used instead of destructive deletion
- evidence files remain in the workspace
- Obsidian stores indexes, summaries, timelines, findings, and reports
- every organizer action is audited
